# Training results

- `yolov11m_baseline/` — the 20-class dish classifier served by the backend (the report's main result). `ablation.csv` lists only runs on the same 20-class split.
- `pilot_8class/` — an earlier run on the 8-class subset that an old class list produced. Not comparable with the 20-class results.
- `incomplete/` — a 20-class stage-1 run that stopped at epoch 15 (out of memory).
